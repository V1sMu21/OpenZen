# 技术调研报告

## 1. Svelte 5

- **官方文档** — [Svelte 5 官方文档](https://svelte.dev/docs) 提供了完整的 API 参考与教程，覆盖组件编写、状态管理及构建工具集成。完整链接：https://svelte.dev/docs
- **Runes 响应式机制** — [Svelte Runes](https://svelte.dev/docs/svelte/runes) 介绍了 `$state`、`$derived`、`$effect` 等 rune，取代了 Svelte 4 中基于编译隐式追踪的响应式语法。完整链接：https://svelte.dev/docs/svelte/runes
- **Reactivity in Depth** — Svelte 5 采用基于函数调用（function-call-based）的响应式追踪方式，编译时将 rune 转换为高效的运行时代码。完整链接：https://svelte.dev/docs

> **总结：** Svelte 5 通过 Runes 和函数式响应式模型彻底重构了状态管理方式，使开发者能更精细地控制响应式边界，同时保持零运行时开销的核心优势。

## 2. Tokio

- **官方文档** — [Tokio 官网](https://tokio.rs) 提供了完整的异步运行时文档、API 引用及教程，涵盖任务调度、网络 I/O 和定时器等核心能力。完整链接：https://tokio.rs
- **GitHub 仓库** — [Tokio Repo](https://github.com/tokio-rs/tokio) 是开源的异步 Rust 运行时项目，包含 runtime、net、io、sync、macros 等模块，活跃贡献者超过 600 人。完整链接：https://github.com/tokio-rs/tokio
- **异步生态核心** — Tokio 是 Rust 生态中使用最广泛的异步运行时，被 Hyper、Axum、SeaORM 等知名框架底层依赖，支持多线程 executor 和协作式调度。完整链接：https://tokio.rs

> **总结：** Tokio 作为 Rust 异步编程的事实标准运行时，凭借其高性能、零成本抽象和完善的生态系统，已成为构建高并发后端服务的首选方案。

## 3. Tailwind CSS v4

- **发布说明** — [Tailwind CSS v4 发布博客](https://tailwindcss.com/blog/tailwindcss-v4) 详细介绍了 v4 的核心变更，包括新引擎 Oxc-based Parser、基于 CSS 声明的 utility-first 语法及性能提升。完整链接：https://tailwindcss.com/blog/tailwindcss-v4
- **迁移指南** — [Migration Guide](https://tailwindcss.com/docs/upgrade-guide) 提供了从 v3 到 v4 的逐步迁移指南，涵盖配置重构（`tailwind.config.js` → CSS 内嵌）、utility class 语法变化和主题系统升级。完整链接：https://tailwindcss.com/docs/upgrade-guide
- **引擎重构** — v4 引入了基于 Rust (Oxc) 的全新解析引擎，将构建速度提升 2–5 倍；同时采用 `@theme`、`@utility` 等 CSS 原生规则替代 JS 配置文件。完整链接：https://tailwindcss.com/blog/tailwindcss-v4

> **总结：** Tailwind CSS v4 通过引擎级重构大幅提升了构建性能并简化了配置方式，是框架历史上最大的一次架构升级。
