`opencode` 在 macOS 上的常见安装路径包括：

| 方式 | 典型路径 |
|------|---------|
| npm global 安装 | `~/npm/bin/opencode` 或 `/usr/local/bin/opencode` |
| Homebrew 安装 | `$(brew --prefix)/bin/opencode`（通常 `/opt/homebrew/bin/opencode`，Apple Silicon；`/usr/local/bin/opencode`，Intel） |
| cargo install | `~/.cargo/bin/opencode` |

在终端里直接跑 `which opencode` 就能确认具体路径。
