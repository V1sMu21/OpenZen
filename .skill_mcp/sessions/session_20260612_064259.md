## 3. 代码块

```python
import numpy as np

class NeuralNetwork:
    """一个简单的神经网络类"""
    
    def __init__(self, layers):
        self.layers = layers
        self.weights = [np.random.randn(j, i) 
                        for i, j in zip(layers[:-1], layers[1:])]
    
    def sigmoid(self, z):
        return 1 / (1 + np.exp(-z))
    
    def forward(self, x):
        for w in self.weights:
            x = self.sigmoid(x @ w)
        return x

nn = NeuralNetwork([784, 128, 10])
```

**麦克斯韦方程组（微分形式）：**

$$
\begin{align}
\nabla \cdot \mathbf{E} &= \frac{\rho}{\varepsilon_0} & \text{(高斯定律)} \\[8pt]
\nabla \cdot \mathbf{B} &= 0 & \text{(高斯磁定律)} \\[8pt]
\nabla \times \mathbf{E} &= -\frac{\partial \mathbf{B}}{\partial t} & \text{(法拉第定律)} \\[8pt]
\nabla \times \mathbf{B} &= \mu_0\mathbf{J} + \mu_0\varepsilon_0\frac{\partial \mathbf{E}}{\partial t} & \text{(安培-麦克斯韦定律)}
\end{align}
$$
