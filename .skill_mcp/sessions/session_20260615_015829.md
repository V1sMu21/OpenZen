Python on macOS 通常在以下路径：

- **系统自带 Python（已移除）**：macOS 12+ 不再预装 Python 2，Python 3 需要自行安装。
- **Homebrew 安装**：`/opt/homebrew/bin/python3`（Apple Silicon）或 `/usr/local/bin/python3`（Intel Mac）
- **官网安装包**：`/Library/Frameworks/Python.framework/Versions/<version>/bin/python3`
- **pyenv 安装**：~/.pyenv/versions/<version>/bin/python3
- **conda/miniconda**：~/miniconda3/bin/python 或 ~/anaconda3/bin/python

终端跑 `which python3` 可快速确认当前使用的路径。
