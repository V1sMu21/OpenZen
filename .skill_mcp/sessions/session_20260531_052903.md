### 动画结构

```
body (深色背景)
 └── scene (底部红线作为"地面")

      └── box (红色渐变方块，旋转+平移)
```

### 关键技术点

| 特性 | 实现方式 |
|------|---------|
| **左右移动** | `@keyframes moveRight` 改变 `left` 从 `-80px` → `calc(100% - 80px)` |
| **旋转效果** | `transform: rotate(360deg)` 同步旋转一整圈 |
| **缓动** | `ease-in-out` 起止慢、中间快 |
| **往复运动** | `infinite alternate` 来回切换 |
| **光效阴影** | `box-shadow` + 渐变背景 |
