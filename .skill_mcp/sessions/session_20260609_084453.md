# Markdown 语法测试面板

欢迎！**这是测试用的文字**，下面涵盖了常见的 Markdown 语法元素：

## 1. 文本样式

支持 `行内代码`、**粗体**、*斜体*、~~删除线~~，以及行内 `代码块` 显示。

## 2. 链接与引用

这是一个 [示例链接](https://example.com)，还有一行经典引用：

> 读一本好书，就是在和高尚的人谈话。——歌德

## 3. 列表与任务

- [x] 已完成项
- [ ] 待办事项
- [ ] 另一个任务

## 4. 代码块

```python
def hello():
    print("Hello, Markdown!")
```

## 5. 表格

| 功能 | 语法 | 说明 |
|------|------|------|
| 粗体 | **text** | 强调文本 |
| 链接 | [text](url) | 超链接 |
| 表格 | \| col1 \| | 对齐列 |

## 6. 数学公式
