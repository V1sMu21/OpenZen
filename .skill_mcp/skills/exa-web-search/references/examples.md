# Web Search Examples

## Basic Search
Search for latest AI news:
```
web_search(query="latest AI breakthroughs 2026")
```

## Specific Query
```
web_search(query="DeepSeek V4.1 release date")
```

## Follow with Fetch
After getting search results, read a page:
```
web_fetch(url="https://example.com/article")
```
