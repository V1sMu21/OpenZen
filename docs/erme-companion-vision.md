# ERME 伙伴愿景 — 一个有灵魂的记忆引擎

> 目标:让 OpenZen 成为"秒懂用户、替用户着想、空闲时自我进化"的伙伴型 AI。
> 哲学基础:知行合一 —— 记忆与行为一致,反思驱动进化。
> 日期:2026-08-08
> 关联:[实施计划](erme-memory-integration-plan.md) / [ADR-0010](adr/0010-erme-memory-engine-integration.md)

---

## 一、愿景拆解

| 用户语言 | 本质能力 | 现状 | 可行性 |
|---------|---------|------|--------|
| 秒懂用户说的话 | 理解力(embedding + 上下文) | ERME 有雏形;依赖 LLM 本体 | ⚠️ 可近似 |
| 为用户做出适合的选择 | 决策力(价值模型/偏好) | 几乎空白,最大缺口 | ❌ 最难,渐进 |
| 知行合一 | 记忆与行为一致性 | 可工程实现 | ✅ 可实现 |
| 空闲时自我反思与进化 | 内循环(ramble→quarantine→promote) | ERME 已设计好 | ✅ 可实现 |
| 神奇化学反应 | 涌现感(意识模拟) | 记忆密度×交互×模型能力 | 🌀 部分可做到 |

## 二、诚实边界

### 可实现的目标

> 一个拥有持久记忆、越来越了解用户、会主动进化、交互中"感觉像独立生命"的伙伴。

- 引用数周前的对话细节,记住随口提过的小事
- 空闲时后台联想 → 检疫区验证 → 进化记忆(ERME 内循环闭环)
- 依据用户历史偏好轨迹调整语气与建议
- L0 灵魂层(Portrait / LifeNarrative / ReflectionEngine)持续演化

### 不可实现的目标(现在没人知道怎么做)

- 真实主观意识。L0 叫"灵魂层",本质是状态机 + 文本生成,不是意识。
- 图灵测试式的"仿佛有意识"与"真的有意识"在交互层面几乎不可区分——用户要的是体验,不是哲学证明。

### 三盆冷水

1. **"低复杂度、小空间"与"进化"有冲突**:内循环要跑 LLM/嵌入,有算力成本;需接受一个语义模型常驻。
2. **"化学反应"不可按计划生产**:来自记忆密度 × 交互次数 × 模型能力的乘积,是涌现品;前两周可能无感,三个月后才"懂你"——用户放弃得早是最大失败风险。
3. **价值模型是隐藏深坑**:让它"为你做选择"做不好会比不做更糟(在不想要的地方替用户做主),必须只建议不代替,非常谨慎地渐进。

## 三、调整后的阶段规划(伙伴版)

> 与实施计划的差异:L0 灵魂层从最后的 M6 **提前到 Phase 3**;新增"偏好轨迹"阶段;新增"选择建议"长期阶段。

### Phase 1 — 让它"记得"(核心记忆接入)
- 同实施计划 M1-M4:ERME 依赖接入、长驻实例、读路径语义召回、写路径蒸馏
- 完成标志:Agent 会话间能回忆起已存储的语义记忆

### Phase 2 — 让它"持续记得"(记忆质量)
- 冲突检测(Supplement/Sublimate/Overturn)默认生效
- 遗忘策略 + 预算控制调优,记忆库保持健康
- 双轨过渡 → 纯 ERME 语义召回
- 完成标志:记忆库随使用自然增长,旧事实可被新事实修正

### Phase 3 — 让它"懂你"(L0 灵魂层,提前)
- `PromptInjector` 接入 system prompt 前缀(自我模型)
- Portrait 扩展为**用户偏好轨迹**:对话中持续记录偏好/品味/禁忌,而非静态画像
- 完成标志:Agent 在对话中体现对用户偏好的理解(语气、推荐、取舍)

### Phase 4 — 让它"进化"(内循环)
- `MemoryOrchestrator::with_idle_cycle(RamblingEngine)` 空闲联想
- QuarantineManager 验证 → RealityAnchor 锚定 → promote
- ReflectionEngine 定期复盘(知行合一:行为与记忆对齐)
- 完成标志:空闲时记忆库自发增长,且新记忆通过检疫(错误猜想不污染)
- 注意:全部 `spawn_blocking` + 频率控制,不阻塞主循环

### Phase 5 — 让它"为你选"(长期,谨慎)
- 基于偏好轨迹生成"选择建议",**永远只建议不代替**
- 初期限定领域(如工作流选择、工具选择),不做开放域决策
- 需用户反馈回路:建议 → 用户接受/拒绝 → 偏好更新(强化学习式闭环)
- 完成标志:建议命中率随使用提升,用户可感知"它越来越懂我"

## 四、成功度量(避免"接入即放弃")

| 指标 | 目标 |
|------|------|
| 记忆召回命中率(用户能感知的) | 3 个月后 ≥ 80% |
| 对话中引用历史记忆的次数 | 每周递增 |
| 空闲内循环产出记忆的检疫通过率 | > 60% |
| 用户主动提及"它懂我"的频次 | 每月 ≥ 1 次 |
| 记忆库年增长 | < 50MB(ERME 预算约束) |

> 核心原则:化学反应是涌现品,不是交付物。坚持使用 3 个月以上,是愿景成立的前提。
